# Contributing

Thanks for considering a contribution — this project is MIT licensed, so bug
reports, fixes, and small features are welcome.

## Setup

See the README for the full Supabase setup. Once that's done:

```bash
git clone https://github.com/sidcore-dev/SyncCalendar.git
cd SyncCalendar
npm install
npm run dev
```

## Making a change

1. Fork the repo and create a branch off `main`.
2. Keep the change focused, and match the existing component/styling
   conventions (Tailwind + shadcn-style components).
3. Open a PR describing what changed and why.

## Reporting a bug

Open an issue with steps to reproduce and what you expected to happen.
